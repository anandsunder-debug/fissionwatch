# Quick Start

1. Open Xcode → File → New → Project → iOS → App.
2. Select SwiftUI, Swift and iOS 15+.
3. Add `Sources/VibrationDetectorApp.swift` to the app target.
4. Add `NSMotionUsageDescription` to Info.plist.
5. Run on a physical iPhone and grant motion access.
6. Test Scanner, History and Plans tabs.

The Swift Package manifest is included for package-oriented organization. For App Store distribution, use an Xcode iOS application target and configure signing, bundle ID, StoreKit products, privacy metadata and App Store Connect.
